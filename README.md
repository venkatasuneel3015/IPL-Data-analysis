# 🏏 IPL Data Analysis & Tableau Dashboard

An end-to-end cricket data analytics project using **SQL and Tableau** to explore Indian Premier League (IPL) match and ball-by-ball data from 2008 to 2020. This project extracts meaningful insights about player performance, team results, match outcomes, and tournament trends through SQL queries and interactive visualizations.

## 🎯 Project Objectives

- Identify top batsmen by total runs and bowlers by wickets.
- Analyze fielding performance, catches, extras, and dismissal types.
- Calculate Chennai Super Kings (CSK) average scores.
- Find teams with the most wins and players with the most Player of the Match awards.
- Identify venues and umpires associated with the most matches.
- Compare the biggest winning margins while chasing and defending.
- Explore whether teams perform better chasing or defending targets.

## 🛠️ Tech Stack

- **SQL** — data querying, aggregation, and analysis
- **Tableau** — dashboards and data visualization
- **CSV** — storage and sharing of query results
- **IPL datasets** — match-level and ball-by-ball data

## 📊 Project Workflow

1. **Data collection:** Obtain IPL match and ball-by-ball datasets.
2. **Data analysis:** Use SQL queries to calculate player statistics, team performance, and match insights.
3. **Export results:** Save query outputs as CSV files for further analysis.
4. **Visualization:** Build Tableau dashboards to present trends and key performance indicators.
5. **Insights:** Compare player, team, and match-level statistics.
